# Super Match — a PM case study for Superleap

A Product Manager take-home case study for [Superleap](https://superleap.com), proposing
**Super Match**: a CRM feature that continuously matches real-estate leads against live
inventory on its own, instead of waiting for someone to check.

The site is a single scrolling case study covering sector research, a rebuilt lead funnel
and workflow, market research on incumbent CRMs, the problem statement and hypothesis,
the proposed solution, a go-to-market plan, and success metrics — plus a working,
click-through prototype of the feature itself.

## Live prototype

The proposed feature is not just described — it's built. See `/prototype` on the deployed
site, or open `reference/super-match-prototype.html` directly.

## Stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion (for the hero's entrance sequence)

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Deploys to Vercel with zero configuration — framework preset "Next.js", no environment
variables required. https://supermatch-a-superleap-pm-assignmen.vercel.app/
